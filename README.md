# Studio Ghibli Photo Filter

A web app that transforms uploaded photos into Studio Ghibli style using image processing techniques.

## Installation

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run the app:
   ```
   python app.py
   ```

3. Open http://127.0.0.1:5000 in your browser.

## Usage

Upload a photo, and the app will apply filters to give it a Studio Ghibli-like appearance.# Ghibli-image
